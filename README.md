Ragi_AI — это решение для создания чатов с ботом и поисковых систем с использованием технологии Retrieval-Augmented Generation (RAG).
Ключевые компоненты:

    Ollama — локальный сервер для работы с LLM .

    Qdrant — векторная база данных для хранения и поиска эмбеддингов документов.

    Веб-интерфейс — управление пользователями, чатами и загрузкой документов.

Основные возможности:

✅ Загрузка документов (PDF, TXT, WORD) в векторную БД.\
✅ Поиск релевантных фрагментов по запросу пользователя.\
✅ Генерация ответов с контекстом из документов.\
✅ Мультипользовательский режим с историей чатов.

## Устанока:

    poetry insatll

    poetry run app.py

После установки зайти на http://хост_ragi_ai:7000 для завершеня установки
